# dembrandt-skills: Systematic Design Tokens & Depth

## Elevation & Depth Scale
- `--elevation-0`: Flat surface, `box-shadow: none`.
- `--elevation-1`: Subtle card lift, `box-shadow: 0 1px 3px 0 rgba(0, 0, 0, 0.05)`.
- `--elevation-2`: Interactive hover state, `box-shadow: 0 4px 12px -2px rgba(0, 0, 0, 0.08)`.
- `--elevation-3`: Floating popovers and dropdowns, `box-shadow: 0 10px 25px -5px rgba(0, 0, 0, 0.12)`.
- `--elevation-4`: Modals and spatial studios, `box-shadow: 0 20px 40px -10px rgba(0, 0, 0, 0.22)`.

## Brand Contrast Standards
- Maintain strict WCAG 2.2 Level AA contrast across all light and dark mode tokens.
- Never place muted text on gray backgrounds without checking minimum 4.5:1 luminosity.
