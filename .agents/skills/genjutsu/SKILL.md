# genjutsu: Creative Coding & Micro-Interactions

## Interaction Thesis
- **Tactile Weight**: Interactive elements must convey physical mass. Clicking a button depresses it by 1–2px (`transform: scale(0.98)` or `translateY(1px)`).
- **Smooth Easing**: Use spring physics (`cubic-bezier(0.16, 1, 0.3, 1)` or `cubic-bezier(0.34, 1.56, 0.64, 1)` for spring overshoot).
- **Ambient Aura**: Neon perimeter scanning, pulse badges, and glow borders that react to satellite observation states.
