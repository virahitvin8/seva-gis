# hallmark: Anti-AI-Slop Design System

## Core Architectural Pillars
- **21 Macrostructures**: Reject the cookie-cutter Hero -> 3 Features -> CTA rhythm. Use split-screen telemetry, bento mosaics, data ribbons, interactive canvases, and dock interfaces.
- **OKLCH Color Scales**: Use perceptually uniform OKLCH color spaces. Reserve high-chroma accents for actionable states; maintain neutral, deep backgrounds.
- **57 Slop-Test Gates**:
  - Gate 1: Contrast ratio >= 4.5:1 on all text.
  - Gate 2: Touch targets >= 44x44px.
  - Gate 3: No unstyled raw browser scrollbars.
  - Gate 4: No dead clicks or non-interactive placeholder buttons.
  - Gate 5: Resilient responsive behavior across all viewports from 320px to 2560px.
