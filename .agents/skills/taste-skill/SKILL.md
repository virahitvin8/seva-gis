# taste-skill: Anti-Slop Frontend Architecture

## Banned AI Design Tropes (Zero-Tolerance)
1. **No generic centered 3-card columns** with floating icons and two lines of filler text.
2. **No purple-to-pink gradient overlays** on everything.
3. **No washed-out gray text** (#999999) on white backgrounds that fails contrast audits.
4. **No fake AI placeholder stats** ("99.9% uptime", "10M+ users") when real engineering telemetry is available.
5. **No emoji spam** in primary button labels or technical headers.

## Taste Principles
- **Editorial Visual Rhythm**: Alternating density, wide asymmetrical hero sections, intentional typographic hierarchy.
- **Micro-Typography**: Small data badges in monospace (`JetBrains Mono`, `uppercase`, `letter-spacing: 0.08em`, font-size: 10–11px).
- **Surface Depth**: Use solid borders with muted tones, dark mode glassmorphism (`backdrop-filter: blur(12px)`), and elevation tokens rather than flat, borderless designs.
- **Living UI**: Elements should respond to hover, focus, and pointer movement with spring physics.
