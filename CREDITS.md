## How to Contribute
We welcome open-source contributions!
1. Fork the repository and create your branch from `main`.
2. Ensure all data remains 100% authentic (no mock, synthetic, or demo data).
3. If changing UI or cartographic outputs, include clear screenshots and test evidence.
4. By contributing, you agree that your contributions are licensed under the applicable project license:
   - Core application, backend, desktop, mobile: **Apache License 2.0**
   - QGIS plugin: **GNU General Public License v3.0 (GPL-3.0-or-later)**
