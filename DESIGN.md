# SEVA.GIS design system (DESIGN.md format)

## Atmosphere
Calm, precise, outdoorsy. Dark forest surfaces for sign-in and map tools, warm paper-green surfaces for the dashboard. One loud accent: lime.

## Colour
- Forest black `#07110c`, forest `#0d1d15`, deep green `#183e30`
- Lime accent `#b6f36a` (actions, highlights), soft lime `#c5dda0`
- Paper `#f2f6ee`, border `var(--border)`, muted text `var(--muted)`
- Status: good `#1a9850`, fair `#fee08b`, bad `#d73027`, info `#80cdc1`

## Type
Manrope 800 for headlines (tight tracking), DM Sans for UI, JetBrains Mono for data labels.

## Components
Pills for actions (999px radius). Cards 12-16px radius. Every number sits next to a scale or legend and a plain-language verdict (Poor, Fair, Good, Healthy).

## Do
Use plain words first, jargon second. Keep legends small. Use real data only.

## Don't
No mock data, no decorative charts, no cartoon map blocks.
